DATE: 07 June 2026

================================================================================
                                 BUG FIXES
================================================================================

[CRITICAL] Keyfile Silent-Fallback Fixed
--------------------------------------------------------------------------------
- PROBLEM: If a keyfile was set but the file was missing or unreadable, the tool
  silently fell back to password-only encryption without any warning.
  The user could unknowingly encrypt data WITHOUT the keyfile being applied,
  while still believing it was part of the key.

- SOLUTION:
  * If a keyfile is configured but cannot be read, the operation is now aborted.
  * A clear error dialog is shown explaining the issue and how to resolve it.

[FIXED] Window & Taskbar Icon
--------------------------------------------------------------------------------
- PROBLEM: The window and taskbar showed Flet's default blue icon instead of
  the app's golden lock icon.
- SOLUTION: Icon is now set at runtime via page.window.icon and bundled
  correctly into the EXE via --add-data.

[FIXED] EXE Startup Crash (libiconv.dll)
--------------------------------------------------------------------------------
- PROBLEM: The EXE crashed on startup with a missing libiconv.dll error.
- SOLUTION: Native DLLs (libiconv.dll, libzbar-64.dll) are now explicitly
  bundled into the EXE via --add-binary.

================================================================================
                              NEW FEATURES
================================================================================

[NEW] Hash Button in Input Area
--------------------------------------------------------------------------------
- A second Hash button is now available directly in the input field area.
- Previously, SHA-256 hashing was only accessible in the output area.

[NEW] Linux Support + Auto-Installer
--------------------------------------------------------------------------------
- Added start_linux.sh: a one-command setup that checks Python, installs all
  required system libraries (libzbar0, libsecret, gtk3, OpenGL/EGL/GLES) and
  Python packages into a local environment, then launches the app.
- Verified end-to-end on Ubuntu 26.04 LTS (Python 3.14): install, GUI launch,
  and cross-save (a file encrypted on Windows decrypts correctly on Linux).

[FIXED] Cross-Platform Clipboard
--------------------------------------------------------------------------------
- Copy buttons used a Windows-only command (clip). Now platform-aware:
  Windows (clip), macOS (pbcopy), Linux (xclip with a built-in fallback).

[CRITICAL] Language Switching Fixed
--------------------------------------------------------------------------------
- PROBLEM: Language dropdown was completely non-functional. Selecting a 
  different language would show the new value in the dropdown, but all UI 
  elements (buttons, labels, hints, error messages) remained in the old language.
  
- ROOT CAUSE: Python closure issue - the lang_code variable was captured by 
  value at definition time, not by reference. The get_lang() function always 
  returned the initial language dictionary.
  
- SOLUTION: 
  * Replaced all state variables with a centralized state dictionary
  * Replaced broken Dropdown with PopupMenuButton (more reliable event handling)
  * Language now changes instantly in real-time without restart

[FIXED] State Management Overhaul
--------------------------------------------------------------------------------
- Converted all nonlocal variables to a centralized state dictionary
- Affected variables: lang_code, is_dark, is_pinned, keyfile_path, 
  selected_file, show_confirm_field, passwords_visible, opacity_val
- This ensures all closures see the current state values

[FIXED] UI Rebuild Preserves User Input
--------------------------------------------------------------------------------
- When changing language or theme, all user input is now preserved:
  * Input text
  * Output text  
  * Password fields
  * Iterations value
  * Selected file
  * Hash display state

GUI VERSION: 3.7.3 (Important fix)
-------------------------------------------------------------------

[NEW & ADDED]
+ Smart Extension Embedding (RAM Mode):
  For files < 100 MB, the original file extension (e.g., .jpg, .docx)
  is now securely embedded within the encrypted file header.
+ Smart Extension Embedding (Stream Mode):
  For huge files (> 100 MB), the file extension is now embedded at the 
  very beginning of the data stream.
+ Internal Marker (TEE-EXT):
  Introduced an invisible byte signature/marker to reliably detect 
  if a file contains embedded metadata/extensions.
+ Keyfile / 2FA Support:
  (From v3.7 base) Added support for optional keyfiles to increase security.

[FIXED / CORRECTED]
* CRITICAL FIX: Small file corruption resolved.
  Previously, small files were incorrectly treated as streams, causing the 
  header not to be stripped upon decryption. The logic now enforces 
  memory mode for these files.
* FIX: File extension restoration.
  Decryption now automatically names the output file correctly 
  (e.g., "decrypted_123456.png" instead of just "decrypted_123456").
* FIX: Streaming logic for large files overhauled.
  The tool now intelligently detects the extension within the first chunk 
  of the stream.

[COMPATIBILITY]
* Legacy Support:
  Files created with older versions (e.g., v3.4, without markers) are 
  still decrypted correctly (as raw files without auto-extension), 
  ensuring no data is cut off or corrupted.

-------------------------------------------------------------------
CLI VERSION: 2.8 (Synced with GUI)
-------------------------------------------------------------------

[NEW & ADDED]
+ GUI Parity:
  Cryptographic logic is now 100% synchronized with GUI v3.7.3.
+ Smart Extension Support:
  The CLI now also supports embedding and automatically restoring 
  file extensions (.bin -> .jpg, etc.).

[CHANGED / ADJUSTED]
* Naming Convention (Encrypt):
  Default output name matched to GUI: "encrypted_{TIMESTAMP}.bin".
* Naming Convention (Decrypt):
  Default output name matched to GUI: "decrypted_{TIMESTAMP}".
  The tool automatically appends the detected extension (e.g., .txt) 
  to this name.

[FIXED]
* Streaming Threshold Fix:
  Streaming threshold raised to 100 MB (synced with GUI) to prevent 
  performance issues and ensure correct header handling for medium-sized files.
